# Bartosz Ptaszyński

Security engineering · systems · agent infrastructure

Security engineer and software generalist. I work where applied security, systems programming, and the messy reality of shipping software overlap.

Most of my public work sits at the security-plus-AI-agents seam: sandboxed runtimes, explicit trust boundaries, capability-gated tools, and automation that leaves evidence behind.

[Website](https://foobarto.me/) · [Writing](https://foobarto.me/blog/) · [Research](https://foobarto.me/research/) · [Now](https://foobarto.me/now/) · [Consulting](https://foobarto.me/consulting/)

## Selected work

- [**glorbo**](https://github.com/foobarto/glorbo) — self-hosted agent orchestration built with Elixir/OTP. Companies, goals, governance, and chat live in files; on Linux, agents run inside kernel-level sandboxes.
- [**stado**](https://github.com/foobarto/stado) — a sandboxed, git-native coding-agent runtime with capability-gated tool execution and signed audit logs.
- [**devbox**](https://github.com/foobarto/devbox) — disposable, CWD-mounted Lima/QEMU development VMs for running AI coding tools behind a real machine boundary.
